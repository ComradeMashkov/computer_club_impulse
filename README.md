## Обзор

Система обрабатывает события входа, ожидания, посадки и ухода клиентов из компьютерного клуба. Рассчитываем:

- Общую выручку по каждому столику (почасовая оплата с округлением вверх).  
- Общее время занятости каждого столика.  
- Автогенерируемые события при некорректных действиях и в конце рабочего дня.

---

## Возможности

- ✅ Современный код на **C++20** с использованием только STL библиотеки.  
- ✅ Обработка всех ошибок входных данных.  
- ✅ Автогенерация событий при:
  - Попытке входа до открытия или после закрытия.  
  - Посадке за занятый или несуществующий столик.  
  - Логике очереди ожидания.  
  - Завершении рабочего дня (очистка клиентов).  
- ✅ **Unit-тесты** на Google Test.  
- ✅ **Интеграционные тесты**, сравнивающие вывод программы с эталонными файлами.

## Структура проекта


## Требования

- Компилятор с поддержкой C++20 (GCC ≥10, Clang ≥12, MSVC 2019+).  
- CMake ≥ 3.10.  
- Google Test.

---

## Сборка

```bash
mkdir build && cd build
cmake -DBUILD_TEST=ON ..
cmake --build .
```

> [!NOTE]
> Опция BUILD_TEST отвечает за сборку unit и интеграционных тестов. Установите OFF, чтобы пропустить тесты.

---

## Запуск

```bash
# Запуск программы:
./task <путь/к/файлу_с_входом.txt> > output.txt

# Пример:
./task tests/test1_in.txt > my_output.txt
```

---

## Тестирование

Юнит-тесты:
```bash
ctest --verbose
```

Интеграционные тесты автоматически запускают `task` для `tests/test*_in.txt` и сравнивают результат с `tests/test*_out.txt`.
